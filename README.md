# ♦️ GANGZ Lua for Neverlose.cc

A feature-packed performance utility and gameplay enhancement script for Counter-Strike: Global Offensive on Neverlose.cc. This is a revision of an earlier 2023 version of the script.

---

## 📜 Historical Note

**GANGZ** was original pioneer behind the **Lag Shift** - an open-source implementation of what is now widely known across the scene as **AirLag Exploit**. 

When first introduced to the general market, it allowed players to break lag compensation mid-air extremely quickly, causing enemy ragebots to miss shots entirely. Its effectiveness eventually led to widespread server-side patches and inspired similar implementations across other scripts on the marketplace.

---

## ✨ Features

* **Anti-Aim & Defensive Logic**: Dynamic defensive pitch/yaw manipulation, custom leg animations, and automated threat-based defensive features.
* **Exploits (Lag Shift)**: Advanced double-tap lag compensation shift, instant DT recharge, and single-tick auto-teleportation.
* **Auto Taser Safety (ATS)**: Constantly measures enemy proximity for any taser equipped enemy players and forces the local player to draw a taser or secondary weapon under threat.
* **Combat & Event Logging**: Detailed hit/miss aimbot logs, player death logs, and automated customizable kill-says.
* **Quality of Life**: Animated Clan Tag, round-start window flash notifications, and grenade double-tap safety overrides.

---

## 🛠️ Usage & Configuration

1. Place the `.lua` file inside your Neverlose scripts directory.
2. Load the script in-game via the **Neverlose Lua Tab**.
3. Use the **Configuration** tab in the UI to export or import settings directly through your clipboard.
